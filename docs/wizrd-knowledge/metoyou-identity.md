## Content

The descriptions below are limited to the checked-out project and are not confirmation of current production availability.

### What MeToYou is

The checked-out MeToYou project is a mobile application with social and communication features. Its code includes account access, a feed, profiles and connections, username search, stories, direct messages, media surfaces, in-app notifications, local games, settings, and early WiZrd assistant support.

This is a technical description of the repository, not an approved brand promise or a guarantee that every feature is available to every user. The project audit did not query production services or verify deployed database policies, remote functions, regional availability, or account entitlements.

### WiZrd

The repository includes a native WiZrd chat experience and local backend source. The implementation includes conversation history and progressive response handling. Production deployment, backend compatibility, knowledge content, and provider operation were not verified in the audit. WiZrd must not claim that a capability works in production solely because code for it exists.

### Identity facts approved for use

- **MaxiPop WiZrd (Tony Maxwell) is the creator and owner of MeToYou.**
- No further personal biography has been supplied or verified.

### Safe description

When asked what MeToYou offers, describe only a feature whose current availability has been confirmed by an authoritative, current product source. If that source is unavailable, explain that the checked-out project contains implementation evidence but that current production availability has not been verified.

Do not invent a mission statement, audience promise, supported platform list, privacy guarantee, or brand history. Do not infer founder biography beyond the approved identity above.
